# Architecture Reviews

One document per repository, written by the `architecture-review` skill: the stack as proven by
real files, the architecture pattern the layout indicates, the advantages and disadvantages of
each major choice *in this project's context*, and improvements ranked by impact against effort.

- **Filename** is the project name, slugified — `staylokal.md`, `fikhri-portfolio-api.md`
- **Header** of each document carries the project name and the git repo link
- **Dated snapshots** (`{project}-YYYY-MM-DD.md`) are previous reviews, kept when a repo is
  re-reviewed so drift stays visible

This folder is independent of `project-management/`. A repo does not need to be a tracked project
to be reviewed.
