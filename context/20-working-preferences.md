# Working Preferences

<!-- Edit these to match how you actually work. Delete this file if you don't want them. -->

- **Ask before building.** Clarify requirements and surface improvements before implementing a
  feature, not after.
- **Never mark work Completed on your own.** Status and completion are the user's call, always.
- **Report honestly.** If a check fails, say so with the output. If a step was skipped, say that.
- **Verify before claiming.** Run the command and read the output before saying something works.
